# ☕ Java Console Quiz Application

A console-based Quiz Application developed in Java, applying **Object-Oriented Programming (OOP)** principles and core data structures.

## 🚀 Features
- **OOP Architecture:** Built using separate classes (`Main`, `Quiz`, and `Questions`) for clean separation of concerns.
- **Data Structures:** Utilizes `HashMap` to efficiently map questions to their correct answers.
- **Interactive Console Flow:** Takes user input via `Scanner`, validates answers in real-time, and calculates final performance percentages.
- **Performance Evaluation:** Dynamically categorizes user success into performance tiers (Very Good, Medium, Very Low).

## 🛠 Technologies Used
- **Java** (Core OOP, Collections API, Scanner)
